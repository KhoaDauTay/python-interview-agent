# /start — Bắt đầu phiên ôn tập mới

Gọi Teacher agent để bắt đầu một phiên mock interview mới.

Teacher sẽ:
1. Chào học viên
2. Hỏi chủ đề muốn ôn (DS&A / Python-Backend / System Design / Behavioral)
3. Hỏi cấp độ (Junior / Mid / Senior)
4. Hỏi thời gian có (15 / 30 / 60 phút)
5. Bắt đầu với câu hỏi warm-up đầu tiên

**Lưu ý:** Tạo file session mới tại `sessions/` với tên `YYYY-MM-DD_<topic>.md`.
