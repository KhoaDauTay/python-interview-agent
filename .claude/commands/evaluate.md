# /evaluate — Chấm điểm câu trả lời

Yêu cầu Teacher đánh giá chi tiết câu trả lời vừa rồi.

Teacher sẽ chấm theo rubric:

```
📊 ĐÁNH GIÁ CÂU TRẢ LỜI
─────────────────────────
Câu hỏi: [câu hỏi]
Điểm: X/10

✅ Điểm tốt:
  - [điều 1]
  - [điều 2]

⚠️ Cần cải thiện:
  - [điều 1]
  - [điều 2]

💡 Gợi ý thêm:
  - [keyword/concept bạn nên research thêm]

🎯 Tóm tắt: [1 câu nhận xét tổng quát]
```

Điểm được lưu vào session file hiện tại.
