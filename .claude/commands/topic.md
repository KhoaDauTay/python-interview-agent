# /topic — Chọn chủ đề cụ thể

Nhảy thẳng vào chủ đề ôn tập mà không cần warm-up.

**Cách dùng:** `/topic <tên chủ đề>`

**Chủ đề hợp lệ:**
- `ds` hoặc `data-structures` → Data Structures & Algorithms
- `python` hoặc `backend` → Python / FastAPI / Backend
- `system-design` hoặc `sd` → System Design
- `behavioral` hoặc `hr` → Behavioral Interview (STAR method)
- `algo` hoặc `algorithms` → Algorithms & Complexity

Teacher sẽ đọc file topic tương ứng trong `topics/` và bắt đầu đặt câu hỏi ngay.

Nếu không truyền argument, Teacher sẽ hỏi bạn muốn chọn chủ đề nào.
